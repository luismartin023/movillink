# Código de Conducta — MovilLink

Este proyecto sigue el espíritu del [Contributor Covenant](https://www.contributor-covenant.org/):

- Respeto y buena fe en issues, PRs y discusiones.
- Crítica al código, nunca a las personas.
- Cero acoso, cero discriminación, cero spam.

El mantenedor ([@luismartin023](https://github.com/luismartin023)) puede
editar, cerrar o rechazar contribuciones que rompan estas reglas.
